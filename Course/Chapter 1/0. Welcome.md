# DevOps Engineering on AWS

## Course Description

DevOps Engineering on AWS teaches you how to combine tools, practices, and the cultural philosophy of DevOps to improve an organization's ability to develop, deliver, and maintain applications and services at high velocity on AWS. This course covers continuous integration (CI), continuous delivery (CD), microservices, infrastructure as code, monitoring and logging, and communication and collaboration.

## Course Objectives

In this course, you will learn how to:

- Describe the advantages of small DevOps teams.
- Identify the roles and responsibilities of members in a typical small DevOps team.
- Use AWS Cloud9 to write, run, and debug code while sharing a cloud-based IDE with your development team.
- Build CI/CD pipelines that include testing and security checks.
- Develop Git branching strategies and integrate them with CI/CD pipelines for multiple environments.
- Use AWS CloudFormation to deploy development, test, and production environments for a software project.
- Design and implement AWS infrastructure that supports DevOps development projects.
- Build a CI/CD pipeline for AWS CloudFormation templates.
- Improve collaboration between development and operations teams by aligning workflows and responsibilities.
- Host secure, highly scalable private Git repositories with AWS CodeCommit.
- Use Amazon Elastic Container Registry (Amazon ECR) to securely store Docker container images and integrate them with AWS CodeBuild and Amazon ECS.
- Automate build, test, and packaging workflows with AWS CodeBuild.
- Integrate security into CI/CD tools and services.
- Implement common deployment strategies such as "all at once," "rolling," and "blue/green."
- Automate software deployments to Amazon EC2, on-premises systems, Amazon ECS (EC2 or Fargate), and AWS Lambda using AWS CodeDeploy.
- Automate release pipelines for build, test, and deployment with AWS CodePipeline.
- Monitor applications and environments using AWS-native tools and technologies.
